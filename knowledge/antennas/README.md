# antennas — pick the right sensor

Dipole, monopole, log-periodic, Yagi, biquad, patch, helical, discone,
whip. Length is `λ/4 = 75 / f_MHz` metres for a quarter-wave monopole
— 17.3 cm at 433 MHz, 6.9 cm at 1090 MHz. VSWR + S11 measurement,
matching networks, cheap kit options (ANT500, RTL-SDR blog v3).
