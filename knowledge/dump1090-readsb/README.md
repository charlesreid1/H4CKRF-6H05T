# dump1090-readsb — the ADS-B decoder

The canonical Mode S / ADS-B extended-squitter decoder. Original was
`dump1090` (Salvatore Sanfilippo); `readsb` (wiedehopf) is the modern
maintained fork with a web UI, JSON API, and Beast/AVR/SBS-1 outputs.

**RX only. TX at 1090 MHz is BLOCKED at the safety gate.**
