# ctf/

CTF puzzle patterns. One file per subgenre (see the seed list in
[../MANIFEST.md](../MANIFEST.md)):

- `rf-triage.md` — first 60 seconds with a mystery signal
- `spectrogram-reading.md` — what a spectrogram tells you
- `unknown-keyfob.md` — is it fixed, rolling, or novel?
- `replay-vs-analyze.md` — when to try replay vs when to decode
- `waterfall-stego.md` — image hidden in the spectrogram
- `packet-flag.md` — the flag is inside a decoded frame
- `two-tone-cipher.md` — DTMF-like keying used as a puzzle
- `numbers-station-decode.md` — HF numbers-stations flavor
- `paging-decode.md` — POCSAG/FLEX with a flag in a message
- `ads-b-recon.md` — an aircraft's squawk is the flag (RX only)

Complements the fast-lookup `docs/ctf_playbook.md` in the top-level docs.
