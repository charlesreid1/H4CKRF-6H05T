# gnu-radio-primer — the SIGINT professional's toolkit

Flow-graph signal-processing framework. GRC is the GUI, Python is the
scripting API, C++ is the block-authoring language. Under the hood of
`gr-osmosdr`, `gr-air-modes`, `gr-ais`, `gr-iridium`, `gr-lora_sdr`,
`gr-pager`. The MCP does **not** shell out to GNU Radio automatically —
this file teaches the operator when to reach for a flowgraph.
