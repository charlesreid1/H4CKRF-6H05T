# urh — Universal Radio Hacker

The GUI-first tool most CTF operators reach for before writing numpy.
Four panes: signal, analysis, generation, simulator. Reads .cs8/.cs16/
.cf32/.wav/SigMF. Automatic modulation detection for OOK/2FSK/PSK.

**The MCP does NOT shell out to URH.** The corpus teaches the operator
to run URH themselves and hand back the resulting IQ or bits for
downstream analysis.
